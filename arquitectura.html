Arquitectura y Ruta de Datos (Datapath)

Estructura interna y bloques funcionales del procesador MIPS32 monociclo.

🔄 Etapas de Ejecución de una Instrucción

El procesador procesa cada instrucción dividiendo el flujo en 5 etapas principales:

  • 1. Instruction Fetch (IF): Obtención de la instrucción desde la Memoria de Instrucciones usando la dirección almacenada en el Contador de Programa (PC).
  • 2. Instruction Decode (ID): Decodificación del código de operación (opcode), lectura de los registros fuente ($rs, $rt) en el Banco de Registros y extensión de signo para valores inmediatos.
  • 3. Execute (EX): Ejecución de la operación en la Unidad Aritmético-Lógica (ALU) o cálculo de direcciones de memoria/salto.
  • 4. Memory Access (MEM): Lectura o escritura en la Memoria de Datos (solo para instrucciones sw y lw).
  • 5. Write Back (WB): Almacenamiento del resultado final (de la ALU o de la Memoria) en el registro de destino ($rd o $rt).

🧩 Componentes Principales del Hardware

1. Contador de Programa (PC - Program Counter)

Registro de 32 bits que contiene la dirección de memoria de la instrucción actual. Se incrementa automáticamente en +4 en cada ciclo (para apuntar a la siguiente palabra de 32 bits).

2. Banco de Registros (Register File)

Contiene 32 registros de 32 bits (desde $zero hasta $ra). Permite leer dos registros simultáneamente y escribir en uno por ciclo de reloj.

3. Unidad Aritmético Lógica (ALU)

Encargada de realizar operaciones aritméticas (ADD, SUB), lógicas (AND, OR) y comparaciones (SLT), además de generar la bandera de cero (Zero Flag) para saltos condicionales.

4. Unidad de Control

Decodifica el opcode y genera las señales que dirigen el flujo de datos (selección de multiplexores, habilitación de escritura en registros/memoria y selección de operación en la ALU).
